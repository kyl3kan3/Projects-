# ClientDock Roadmap

## Phase 0 — Setup (week 0)
- Next.js + Postgres running; a hardcoded portal renders with theme config

**Done when:** a magic link opens a scoped client session on a demo portal.

## Phase 1 — MVP (weeks 1–5)
- Portal builder with modules (timeline, files, messages); templates + duplication
- Magic-link client access; view-as preview; portal-view analytics
- File versioning + approval rounds with audit trail
- Branding (logo/colors) + Solo tier billing (Stripe)
- Notification emails; freshness stamps

**Done when:** 5 pilot agencies onboard real clients; ≥60% of invited clients open the portal in week 1; an approval round completes end-to-end.

## Phase 2 — Launch (weeks 6–9)
- Full white-label: custom domains (CNAME wizard) + agency-domain email (DKIM wizard)
- Email-reply threading (inbound parsing)
- Stripe Connect invoice embed
- Launch: agency communities, comparison pages (Copilot/SuiteDash), template gallery SEO

**Done when:** 30 paying workspaces; Agency-tier (white-label) ≥40% of new revenue; DKIM wizard completion ≥80% unassisted.

## Phase 3 — Growth (months 3–8)
- Studio tier: team roles, API/Zapier, client analytics dashboard
- Integrations: Slack notifications, Figma/Loom embeds, QuickBooks invoice sync
- Client mobile web polish + PWA notifications
- Annual pricing; agency-partner referral program

**Done when:** $10k MRR; net revenue retention >105%; client-adoption metric (weekly portal views per active portal) trending up.
