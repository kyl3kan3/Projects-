# RankRadar Roadmap

## Phase 0 — Setup (week 0)
- Next.js + Postgres + Redis running; DataForSEO sandbox account wired
- One keyword can be checked end-to-end and charted

**Done when:** a seeded project shows a real position history chart from live checks.

## Phase 1 — MVP (weeks 1–5)
- Projects, keyword CRUD with tags/locations/devices; nightly check fan-out
- Position history charts + SERP-feature tracking; competitor share-of-voice
- Alerts (drops, page-1 entries) via email
- Stripe tiers with keyword caps; usage dashboard
- GSC connect (clicks/impressions overlay)

**Done when:** 5 pilot agencies track ≥200 keywords each for 2 weeks with zero missed check cycles.

## Phase 2 — Launch (weeks 6–9)
- AI content briefs (grounded pipeline) + credit packs
- White-label hosted reports + scheduled PDF email
- Free SERP-checker tool + comparison landing pages (SEO flywheel)
- Launch: SEO communities, build-in-public thread, affiliate program for agencies

**Done when:** 25 paying teams; ≥40% of actives generate ≥1 brief/mo; report links opened by end clients (proof of embed).

## Phase 3 — Growth (months 3–6)
- API (Scale tier); Looker Studio connector
- Keyword-gap discovery suggestions ("track these 40 terms competitors own")
- AI Overview visibility tracking as a headline feature
- Annual plans; LTD retirement if used at launch

**Done when:** $10k MRR; logo churn <4%/mo; data cost ≤30% of revenue.
