# ResumeRocket Roadmap

## Phase 0 — Setup (week 0)
- Next.js + Postgres running; one ATS-safe template renders to PDF cleanly

**Done when:** a hardcoded resume exports to a pixel-clean PDF.

## Phase 1 — MVP (weeks 1–5)
- Import (PDF/DOCX/LinkedIn) → structured profile with confirm/edit UI
- Builder on 3 ATS-safe templates; posting parser + gap analysis
- Tailoring engine with fabrication guard + flagged suggestions
- Cover letters (3 tones); match score; PDF/DOCX export
- Stripe weekly/monthly passes; free tier with watermark

**Done when:** 20 beta users tailor real applications; zero fabricated claims survive the guard in adversarial testing; import handles 90% of real-world resumes without manual fixup.

## Phase 2 — Launch (weeks 6–9)
- **Free ATS X-ray checker** as a standalone tool page (the SEO engine)
- Application tracker lite; alumni win-back emails
- Programmatic SEO: role × situation pages seeded (100 pages, quality-gated)
- Launch: Product Hunt, r/resumes teardowns, career-creator affiliates

**Done when:** checker converts ≥5% of tool users to signup; 200 paying passes; honest-billing NPS evident in reviews.

## Phase 3 — Growth (months 3–8)
- LinkedIn headline/summary rewriter; interview-prep add-on (question bank from posting)
- Career-coach/university multi-seat tier
- SEO scale-out (1,000+ quality-gated pages); layoff-wave content playbook
- Localization (UK/CA/AU formats first)

**Done when:** $10k MRR; organic ≥60% of signups; weekly-pass → monthly upgrade path measurable.
