# CartBoost Roadmap

## Phase 0 — Setup (week 0)
- Shopify partner account + dev store; embedded app skeleton authenticates (OAuth + App Bridge)
- Post-purchase extension renders a hardcoded offer on a dev-store order

**Done when:** a test checkout shows the extension and one-click add commits to the order.

## Phase 1 — MVP (weeks 1–5)
- Funnel + offer builder with trigger rules; priority evaluation API
- Accept/decline flows + downsell step; event attribution via webhooks
- Revenue dashboard (rollups, acceptance rates); Shopify Billing tiers + free-tier cap
- Onboarding: template funnels by vertical, 5-minute setup path

**Done when:** 5 pilot stores run live funnels; attribution matches Shopify order data exactly; setup-to-live median <10 minutes.

## Phase 2 — App Store launch (weeks 6–9)
- App review submission (GDPR webhooks, billing compliance, performance pass)
- Listing optimization (keywords, screenshots, demo video); review-request flow post-value ("CartBoost just passed $500 for you — mind leaving a review?")
- A/B testing feature; thank-you-page offers

**Done when:** approved + listed; first 50 installs; ≥15 reviews ≥4.5★; free→paid ≥8%.

## Phase 3 — Growth (months 3–8)
- AI offer suggestions (order-pair mining); analytics export
- Agency partner program; annual pricing
- Cart-page + product-page cross-sell placements (expansion surface)
- Explore WooCommerce port only after Shopify motion is compounding

**Done when:** $8k MRR; app-store organic ≥60% of installs; churn <4%/mo with revenue-dashboard engagement correlated.
