# LingoLoop Roadmap

## Phase 0 — Setup (week 0)
- Expo app boots; session server echoes a WebSocket round trip
- Deepgram + Claude + TTS keys wired in a CLI prototype of the pipeline

**Done when:** a terminal prototype holds a spoken Spanish exchange end-to-end.

## Phase 1 — MVP (weeks 1–6)
- Voice session flow in-app with streaming latency <1.5s first-audio
- Level-calibration onboarding; 10 scenarios × 5 languages (ES/FR/DE/IT/PT)
- Post-session correction report; mistake memory + warm-up drills
- Text mode; RevenueCat paywall (annual w/ trial hero, monthly fallback); free tier limit

**Done when:** 25 beta testers average ≥4 sessions/week for 2 weeks and self-report the corrections as accurate; cost per session ≤$0.15.

## Phase 2 — Launch (weeks 7–10)
- Store assets + ASO pass; onboarding polish (first session within 2 minutes of install)
- Streaks, session history, share-card ("30-day speaking streak")
- Launch: TikTok creator seeding, r/languagelearning, Product Hunt

**Done when:** live in both stores; trial-start ≥8% of installs; trial→paid ≥35%; D7 retention ≥20%.

## Phase 3 — Growth (months 3–8)
- More languages (JA/KO/ZH need speech-stack validation first)
- Pronunciation scoring (phoneme-level feedback); custom scenario builder
- Paywall experiments via RevenueCat; win-back offers
- Referrals (give a month / get a month)

**Done when:** $10k MRR; annual mix ≥55% of new subs; speech cost per session trending down.
