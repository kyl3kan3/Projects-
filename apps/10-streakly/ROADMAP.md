# Streakly Roadmap

## Phase 0 — Setup (week 0)
- Expo project boots on iOS + Android simulators; expo-router tabs in place
- RevenueCat project created; products configured in App Store Connect / Play Console
- SQLite schema migrated on first launch

**Done when:** app installs, tabs navigate, sandbox purchase completes.

## Phase 1 — MVP (weeks 1–4)
- Habit CRUD with schedule rules (daily / X-per-week)
- Today screen with streak computation (current, longest, grace day)
- Focus timer (pomodoro) linkable to a habit; session history
- Local notifications for habit reminders
- Paywall: free tier = 3 habits; RevenueCat offerings wired ($3.99/wk trial, $6.99/mo, $39.99/yr, $69.99 lifetime)
- Onboarding flow that creates the first habit before the paywall is ever shown

**Done when:** a tester can run a 7-day streak with reminders and upgrade via sandbox purchase.

## Phase 2 — Launch (weeks 5–8)
- Home-screen widgets (iOS WidgetKit + Android Glance) — streak flame + quick-complete
- Stats tab: completion heatmap, weekly review summary
- App Store assets, ASO keyword pass ("habit tracker", "streak", "focus timer")
- Paywall A/B test #1 (trial length) via RevenueCat experiments

**Done when:** approved on both stores; >100 downloads; trial-start rate >8% of installs.

## Phase 3 — Growth (months 3–6)
- Accountability circles (invite 2–5 friends, shared streak view) — the retention moat
- Streak-repair (watch ad / one-tap purchase) — monetizes lapses instead of churning them
- Apple Watch complication + quick-log
- Referral program (give a month, get a month)

**Done when:** D30 retention >12%; MRR >$5k; circles used by >15% of actives.
